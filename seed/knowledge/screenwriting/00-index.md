## Reading order for a project

Feature or short: 01 → 02 → 03 → 04 → 06 + 07 → 05 → the diagnostics in each doc.
Series: 01 (series table) → 09 → 04 → 08 → 10 → 05 + 07.
Commercial piece: 13 (or 14) → the `short-form-script` skill → 05 for the VO → 06 for the shots.

## Rules that apply across the folder

0. Spelling: the authored docs (00, 13, 14) and the skills use US spelling; the distilled docs 01–12 keep the distillers' British spelling and are exempt.

1. Output language follows the brief; these docs are English, the script can be es-419.
2. Every figure in a script (price, rating, count) must come from the brief's proof points or a read source; otherwise it is written as `[PROOF NEEDED: …]`. This is the same provenance rule Jarvis applies to KB and Sheets writes.
3. The diagnostics are advisory gates, not blockers: run them, list what is flagged, fix what you can, report the rest.
4. Nothing here is legal, medical or compliance advice; claims and disclosures are the operator's review.
