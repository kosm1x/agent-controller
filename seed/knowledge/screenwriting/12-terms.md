# Screenwriting and television craft glossary
**Read this when:** you need the canonical English craft term before writing or reviewing any doc in this folder, or a request uses an ambiguous word (outline vs treatment vs synopsis, format, franchise, the board).
**Source:** distilled 2026-09-12 from jtydhr88/screenwriting-skills `sw-workflow` (terms.md, method only); underlying books: none named by the skill; per-term credits (McKee, Field, Snyder, Egri, Cron) are those the source table gives.

## Usage rules
1. Reply in the user's language, but every concept below keeps its original English term; never improvise a translation or a synonym.
2. A concept missing here: find the term in its original language, use it, and gloss it once in one clause. Never silently invent a name.
3. "Where used" gives the doc number; filenames are in the Pairs-with line above.

## Film craft (structure, premise, character)
| Term | Definition (one sentence) | Where used |
|---|---|---|
| story triangle | McKee's map of the three plot designs below. | 03 |
| archplot / miniplot / antiplot | McKee: classical design, minimalist design, anti-structure. | 03 |
| paradigm | Field's three-act model of a feature. | 03 |
| plot point I / II | Field: the turns that close acts I and II. | 03 |
| inciting incident | McKee: the event that upsets the protagonist's balance and starts the story. | 03 |
| progressive complications | McKee: escalating obstacles between inciting incident and crisis. | 03 |
| crisis / climax / resolution | McKee: final dilemma, decisive action, aftermath. | 03 |
| midpoint | Snyder / Field: the mid-story reversal. | 03 |
| act | a major movement of the story. | 03, 08 |
| sequence | McKee: a run of scenes building to a larger turn. | 03, 06 |
| scene | one unit of action in one time and place. | 06 |
| beat | McKee: the smallest unit, one action and its reaction. | 06 |
| beat sheet | Snyder's BS2 in features; the per-episode beat list in TV (see below). | 03, 10, 13 |
| the board | the 40-card layout of the story; NOT a storyboard. | 03 |
| opening image / final image | Snyder: the before/after snapshots bracketing the film. | 03 |
| theme stated | Snyder: the early line that names the theme. | 03 |
| catalyst | Snyder's name for the inciting incident. | 03 |
| debate | Snyder: the hesitation stretch after the catalyst. | 03 |
| promise of the premise | Snyder: the section delivering the concept; also "fun and games". | 03 |
| all is lost | Snyder: the low point. | 03 |
| dark night of the soul | Snyder: the reflection beat after the low point. | 03 |
| turning point | any beat that reverses the story's direction. | 03 |
| subplot | McKee: a secondary line; in TV say B story. | 03, 08 |
| premise | Egri: the one-sentence proposition the play proves. | 02 |
| controlling idea | McKee: the value plus the cause the ending affirms. | 02 |
| logline | a one-sentence statement of the story. | 02, 13 |
| high concept | a premise pitchable in one line. | 02, 13 |
| spine / through-line | the protagonist's single line of action across the story. | 02, 04 |
| three-dimensional character | Egri: physiology, sociology, psychology. | 04 |
| characterization vs true character | McKee: observable traits vs choices under pressure. | 04 |
| orchestration | Egri: casting characters so they contrast and collide. | 04 |
| unity of opposites | Egri: opponents bound so neither can quit. | 04 |
| pivotal character | Egri: the one who forces the conflict; NOT necessarily the protagonist. | 04 |
| protagonist / antagonist | lead and opposing force; the antagonist need not be a villain. | 04 |
| arc | a character's change across the story. | 04 |
| want vs need | conscious goal vs unconscious lack. | 04 |
| misbelief | Cron: the false belief the protagonist must shed. | 04 |
| rising / static / jumping conflict | Egri: conflict that builds, stalls, or skips steps. | 04 |

## Television structure

|---|---|---|
| franchise | the series engine that generates episodes; NOT a commercial brand. | 09 |
| procedural | case-of-the-week series. | 08, 09 |
| serial | strongly continuing series. | 08 |
| anthology | series of self-contained episodes or seasons. | 08 |
| teaser / cold open | the scene before the titles. | 08, 11 |
| act out | the end-of-act hook before a break. | 08, 11 |
| cliffhanger | the unresolved end-of-episode hook. | 08 |

| pilot | the first episode, written to sell the series. | 08, 09 |
| A / B / C story | main, secondary, tertiary lines of an episode. | 08, 11 |

| bottle episode | an episode confined to standing sets and cast. | 08 |
| springboard | a short episode idea offered to the room. | 10 |
