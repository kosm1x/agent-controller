## 8. The three cases, re-traced after the gate

- **A — agent adds a package to solve a task.** Trigger: `shell_exec npm install x` or `npx x`. Deployed: refused by name lookup (layer 1) in every spelling that reaches a package manager through PATH, and by the string gate (layer 2) for absolute-path literals; refusal text names the operator hand-off. The agent reports the line; the operator installs (min-release-age 7 applies), deploys, and deploy.sh rebuilds the sandbox image on lockfile drift. Who notices: the operator, before anything runs. A rename (`ln -s /usr/bin/npm zz`), a PATH rewrite (`PATH=/usr/bin npm`, `sudo npm`, `env -i`) and a `package.json` script body are refused by the string gate as written. Residual route: an absolute path or PATH assignment assembled at run time inside an interpreter program; who notices then: the operator at deploy (lockfile drift), or nobody if the install left no lockfile change (`npx` of an uncached package). That residual is the reason the structural closer (egress deny + read-only `node_modules`), the case-C monitor and `npm audit signatures` stay queued.
- **B — a transitive ships a new version.** Nothing moves until an operator `npm install`/`npm update`; CI and deploy are lockfile-faithful. When it moves, `allowScripts` gates its install script and min-release-age refuses versions under 7 days old. Who notices: the operator at install time, CI on the next push.
- **C — a direct dependency is abandoned or changes hands.** Not observable from the lockfile; `npm run audit:deps -- --registry` shows publish date and maintainer count per direct dependency, which is the only registry-visible signal. Who notices: whoever runs the audit; no scheduled run exists (a candidate for a monthly ritual, not shipped).
